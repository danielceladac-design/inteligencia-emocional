# Proyecto: Inteligencia Emocional

Este proyecto es una aplicación web interactiva desarrollada para informar sobre la Inteligencia Emocional, sus pilares fundamentales y herramientas prácticas para el autoconocimiento.

##  Características
- **Página de Inicio** con información estructurada en secciones.
- **Barra de Navegación** fluida.
- **Buscador/Filtro interactivo** desarrollado en JavaScript.
- **Quiz / Autoevaluación** para medir habilidades emocionales.
- **Formulario de Contacto** (Simulación).
- **Diseño Responsivo** adaptable a computadoras y celulares.

##  Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Git / GitHub Pages
